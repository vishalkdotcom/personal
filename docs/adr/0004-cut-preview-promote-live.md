# Cut Preview; promote Live

The App Shell shipped an in-shell Preview surface (header chip, desktop slide-over, mobile fullscreen) that never embedded real product UI — hosts block iframes, and stub device frames read as broken. We **cut Preview entirely** and make Public Storefront honesty **Live only**: Context Rail primary **Open live ↗** (external) plus a muted host line; Internal Dossiers omit Live. Rejected for this pass: keeping a disabled/stub Preview, or fighting iframe embeds. Reconsider a Preview-style surface later only if authored desktop-vs-mobile screenshot sets exist that Live cannot show. This decision is locked by Spec `app-shell-residual-restore` and **intentionally supersedes** rewrite/amendment Preview locks. The same Spec also locks dead `/work/<folder-slug>` URLs (no route, no redirect) as an intentional supersession of prior folder-index routing — that removal ships in the sibling folder-index ticket, not this one.

# Oxlint and Oxfmt for lint and format

The portfolio repo needs a lint/format Quality Gate beside existing `bun check` (`tsc --noEmit`) and Vitest. We choose **oxlint + oxfmt** as the engines: fast, low config surface, Bun-friendly, and a clean fit for a small SolidJS 2 + Vite tree. **Typechecking stays with `tsc`** — the linter does not own types. Rejected: **Ultracite** (preset wrapper that collides with our `check` script and ships an empty Oxlint Solid preset), **ESLint + Prettier** (heavier than we need), and **Biome** (reasonable one-binary alternative, not chosen once Oxc was preferred). Solid-specific lint rules are deferred until the Solid 2 lint story is clearer; Vitest-aware Oxlint config is in scope. Enforcement is Lefthook on staged oxfmt/oxlint, plus CI running format:check, lint, typecheck, test, and build.
